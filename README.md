# 本地小说阅读器

> 15MB，无广告、无账号、不上传任何数据。

一个把书源和阅读器都塞进单机 APK 的小说阅读工具。Python 引擎内嵌，启动后只在 `127.0.0.1` 上跑，书架、进度、偏好全部存在本机，卸载即销毁。

---

## 为什么自己做？

市面上的阅读 App 有三个绕不过去的问题：

1. **广告和会员** —— 想看个书先过三道弹窗。
2. **书源失效了没人修** —— 源挂了只能等更新，或者自己动手。
3. **想自己维护书源，又不放心把数据交给别人** —— 要么功能受限，要么隐私换便利。

所以把能想到的都做进去了。

---

## 功能

### 一、书源

- 合计 **685 个**书源，当前启用 **669 个**
- 内置 **242 个**，已用真实引擎逐个测过，其中 **165 个**能搜出结果
- 支持直接导入 **Legado 格式**书源，老书源不用重新配

### 二、搜索

- 一次**并发搜索 400 个源**，结果边搜边出
- 同名作品自动合并成一条，一本书最多保留 **8 条备用线路**
- 某个源失效时，可在详情页**直接换源**，不用重新搜一遍

### 三、阅读器

- 字号、行距、页宽可调
- 衬线 / 黑体字体切换
- 三种背景
- 章内进度精确到百分比，退出自动记住位置
- 左右滑动翻章，长按选词不被打断

### 四、隐私

- **没有服务器**。Python 引擎直接内嵌在 APK 里
- 启动后只在本机 `127.0.0.1` 运行，外部访问不到
- 书架、进度、偏好全部存在本机
- **卸载即销毁**，不留云端副本

---

## 关于体积

15MB，因为内嵌了 **Python 3.12** 运行时和**全部书源**。

换来的是**完全离线**，不依赖任何外部服务。

## 已知限制

**书源可用率不是 100%。**

失败大多不是源死了，而是：

- 站点改成 JS 渲染
- 需要登录才能访问
- 站点改版

因此应用会**逐源显示失败原因**，而不是整体报错 —— 你能看到哪个源挂了、为什么挂，方便自己修。

## 适合谁

- 习惯自己维护书源的人

- 在意数据不出本机的人

## 不适合谁

- 想要开箱即用、一键追更的
- 需要跨设备同步的
