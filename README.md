# 本地小说阅读器

> 15MB，无广告、无账号、不上传任何数据。

一个把书源和阅读器都塞进单机 APK 的小说阅读工具。Python 引擎内嵌，
启动后只在 127.0.0.1 上跑，书架、进度、偏好全部存在本机，卸载即销毁。

## 为什么自己做？
（三个痛点，同你的原文）

## 功能
### 一、书源
- 合计 685 个书源，当前启用 669 个
- 内置 242 个，已用真实引擎逐个测过，其中 165 个能搜出结果
- 支持直接导入 Legado 格式书源

### 二、搜索
- 一次并发搜索 400 个源，结果边搜边出
- 同名作品自动合并成一条，一本书最多保留 8 条备用线路
- 某个源失效时，可在详情页直接换源

### 三、阅读器
- 字号、行距、页宽可调；衬线/黑体；三种背景
- 章内进度精确到百分比，退出自动记住位置
- 左右滑动翻章，长按选词不被打断

### 四、隐私
- 没有服务器，Python 引擎内嵌在 APK 里
- 只在本机 127.0.0.1 运行，外部访问不到
- 数据全在本机，卸载即销毁
